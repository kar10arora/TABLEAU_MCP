# Generated Workbooks

This directory contains Tableau workbooks (.twb files) generated by the MCP server.

## Overview
All generated workbooks will be saved here by default unless a custom output path is specified.

## File Naming
- Default: `generated_workbook.twb`
- Custom names can be specified via the MCP tool parameter

## Opening Generated Workbooks
1. Open Tableau Desktop
2. File → Open
3. Navigate to this directory
4. Select the `.twb` file

## Notes
- `.twb` files are XML-based and reference external data sources
- Ensure the CSV dataset is accessible when opening workbook
- Generated files are excluded from git (see .gitignore)
- Files are overwritten by default unless custom names used

## Troubleshooting
If workbook doesn't open:
- Check Tableau Desktop version compatibility
- Verify dataset path is correct
- Check XML validity
- Review generation logs for errors
